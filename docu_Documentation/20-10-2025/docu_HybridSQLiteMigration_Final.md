# Hybrid SQLite Migration - Final Specification

**Priorita:** 🔴 P3 (Kritická)
**Čas:** 26-34 hodín
**Dependencies:** UI Virtualization (ViewportManager)

---

## 📋 Prehľad

Migrácia z InMemoryRowStore na Hybrid SQLite Model pre podporu 10M+ riadkov:
- **SQLite** = Persistence (disk, ALL rows)
- **LRU Hot Cache** = Frequently accessed rows (RAM, 1000 rows)
- **ViewportManager POCO Cache** = Viewport performance (RAM, 1000-2000 rows)

### KRITICKÁ ZMENA POŽIADAVKY

❌ **GetAllRowsAsync** → Mark as TODO for later refactoring
✅ **GetAllRowsAsync** → **ELIMINATE IMMEDIATELY** (throw exception + force refactor!)

### KĽÚČOVÁ OTÁZKA: Potrebujem POCO cache ak mám SQLite?

**ODPOVEĎ: ÁNO!**

Dôvod:
- **SQLite** = Persistence na disku (ALL rows, ~1TB pre 10M rows)
- **POCO Cache** = Viewport buffer v RAM (visible + buffer rows)
- **NIE duplikácia** - rôzne účely, spolupracujú!

Komponenty sú **hybrid medzi SQLite a klasikou**:
```
[SQLite Disk Storage] ←→ [LRU Cache (1000)] ←→ [POCO Cache (1000-2000)] ←→ [ViewModels (1000)]
     (persistence)        (hot data)           (viewport buffer)          (UI layer)
```

---

## 🎯 Ciele

1. **10M rows support:**
   - RAM: ~700 MB - 1.2 GB (vs NEMOŽNÉ with InMemory)
   - Disk: ~1 TB (SQLite file)

2. **Streaming operations:**
   - StreamRowsAsync = primary metóda
   - GetAllRowsAsync = ELIMINATED (throws exception!)

3. **Performance:**
   - LRU cache hit rate: >90%
   - Insert/Delete: O(log n) (SQLite index)

```csharp
/// Hybrid SQLite-backed row store with LRU hot cache.

{
    private readonly SqliteConnection _connection;
    private readonly SemaphoreSlim _dbLock = new(1, 1);
    private readonly LRUCache<int, IReadOnlyDictionary<string, object?>> _hotCache;
    private readonly ILogger<HybridRowStore> _logger;

    private const int HOT_CACHE_SIZE = 1000;
    private bool _disposed = false;

    public HybridRowStore(string dbPath, ILogger<HybridRowStore> logger)
    {
        _logger = logger;
        _hotCache = new LRUCache<int, IReadOnlyDictionary<string, object?>>(HOT_CACHE_SIZE);

        // Create database file if not exists
        var directory = Path.GetDirectoryName(dbPath);
        if (!string.IsNullOrEmpty(directory) && !Directory.Exists(directory))
        {
            Directory.CreateDirectory(directory);
        }

        // Open connection

        _connection = new SqliteConnection(connectionString);
        _connection.Open();

        // Configure SQLite
        ConfigureDatabase();

        // Initialize schema
        InitializeSchema();

        _logger.LogInformation("HybridRowStore initialized: {DbPath}", dbPath);
    }

    private void ConfigureDatabase()
    {
        ExecuteNonQuery("PRAGMA journal_mode=WAL");
        ExecuteNonQuery("PRAGMA synchronous=NORMAL");
        ExecuteNonQuery("PRAGMA cache_size=10000");
        ExecuteNonQuery("PRAGMA temp_store=MEMORY");
    }

    private void InitializeSchema()

    /// <summary>
    /// Gets row by index (uses LRU cache).
    /// </summary>
    public async Task<IReadOnlyDictionary<string, object?>?> GetRowAsync(
        int rowIndex,
        CancellationToken cancellationToken = default)
    {
        // Check hot cache
        if (_hotCache.TryGet(rowIndex, out var cachedRow))
        {
            _logger.LogTrace("Cache HIT: row {Index}", rowIndex);
            return cachedRow;
        }

        // Cache miss - load from SQLite
        await _dbLock.WaitAsync(cancellationToken);
        try
        {
            using var command = _connection.CreateCommand();
            command.CommandText = "SELECT DataJson FROM DataRows WHERE RowIndex = @index";
            command.Parameters.AddWithValue("@index", rowIndex);

            var json = (string?)await command.ExecuteScalarAsync(cancellationToken);
            if (json == null)
                return null;

            var row = JsonSerializer.Deserialize<Dictionary<string, object?>>(json);
            if (row == null)
                return null;

            // Add to hot cache
            _hotCache.Add(rowIndex, row);

            _logger.LogTrace("Cache MISS: row {Index} loaded from SQLite", rowIndex);
            return row;
        }
        finally
        {
            _dbLock.Release();
        }
    }

    /// <summary>
    /// ❌ ANTIPATTERN - DO NOT USE for 10M rows!
    /// This method throws NotSupportedException to force refactoring.
    /// Use StreamRowsAsync instead!
    /// </summary>
    [Obsolete("Use StreamRowsAsync for large datasets. This method throws exception.")]
    public Task<IReadOnlyList<IReadOnlyDictionary<string, object?>>> GetAllRowsAsync(

    /// <summary>
    /// ✅ STREAMING - Primary method for processing rows.
    /// Constant memory usage regardless of row count.
    /// </summary>
    public async IAsyncEnumerable<List<IReadOnlyDictionary<string, object?>>> StreamRowsAsync(
        bool onlyFiltered,
        bool onlyChecked,
        int batchSize,
        [EnumeratorCancellation] CancellationToken cancellationToken = default)
    {
        await _dbLock.WaitAsync(cancellationToken);
        try
        {
            using var command = _connection.CreateCommand();
            command.CommandText = "SELECT RowIndex, DataJson FROM DataRows ORDER BY RowIndex";

            using var reader = await command.ExecuteReaderAsync(cancellationToken);

            var batch = new List<IReadOnlyDictionary<string, object?>>(batchSize);

            while (await reader.ReadAsync(cancellationToken))
            {
                var rowIndex = reader.GetInt32(0);
                var json = reader.GetString(1);

                var row = JsonSerializer.Deserialize<Dictionary<string, object?>>(json);
                if (row == null)
                    continue;

                // Apply filters
                if (onlyFiltered)
                {
                    // TODO: Apply filter logic
                }

                if (onlyChecked)
                {
                    if (!row.TryGetValue("__isChecked", out var isChecked) || !(isChecked is bool b && b))
                        continue;
                }

                batch.Add(row);

                // Yield batch when full
                if (batch.Count >= batchSize)
                {
                    yield return batch;
                    batch = new List<IReadOnlyDictionary<string, object?>>(batchSize);
                }
            }

            // Yield remaining
            if (batch.Any())
                yield return batch;
        }
        finally
        {
            _dbLock.Release();
        }
    }

    /// <summary>
    /// Appends rows to end (bulk insert).
    /// </summary>
    public async Task AppendRowsAsync(
        IEnumerable<IReadOnlyDictionary<string, object?>> rows,
        CancellationToken cancellationToken = default)
    {
        await _dbLock.WaitAsync(cancellationToken);
        try
        {
            var nextIndex = await GetRowCountInternalAsync();

            using var transaction = _connection.BeginTransaction();

            foreach (var row in rows)
            {
                var rowId = Guid.NewGuid().ToString();
                var json = JsonSerializer.Serialize(row);

                using var command = _connection.CreateCommand();
                command.CommandText = @"
                    INSERT INTO DataRows (RowId, RowIndex, LastModified, CreationType, DataJson)
                    VALUES (@rowId, @rowIndex, @lastModified, @creationType, @dataJson)";

                command.Parameters.AddWithValue("@rowId", rowId);
                command.Parameters.AddWithValue("@rowIndex", nextIndex++);
                command.Parameters.AddWithValue("@lastModified", DateTime.UtcNow.ToString("o"));
                command.Parameters.AddWithValue("@creationType",
                    row.TryGetValue("__creationType", out var ct) ? ct?.ToString() ?? "AutoGenerated" : "AutoGenerated");
                command.Parameters.AddWithValue("@dataJson", json);

                await command.ExecuteNonQueryAsync(cancellationToken);
            }

            transaction.Commit();

            // Invalidate cache
            _hotCache.Clear();

            _logger.LogInformation("Appended {Count} rows", rows.Count());
        }
        finally
        {
            _dbLock.Release();
        }
    }

    /// <summary>
    /// ✅ NEW METHOD - Inserts row at specific index (STREAMING).
    /// Updates RowIndex for all rows after insertion point.
    /// NO GetAllRows needed!
    /// </summary>
    public async Task InsertRowAtAsync(
        int index,
        IReadOnlyDictionary<string, object?> row,
        CancellationToken cancellationToken = default)
    {
        await _dbLock.WaitAsync(cancellationToken);
        try
        {
            using var transaction = _connection.BeginTransaction();

            // STEP 1: Shift all rows at/after index
            using (var updateCmd = _connection.CreateCommand())
            {
                updateCmd.CommandText = @"
                    UPDATE DataRows
                    SET RowIndex = RowIndex + 1
                    WHERE RowIndex >= @index";
                updateCmd.Parameters.AddWithValue("@index", index);
                await updateCmd.ExecuteNonQueryAsync(cancellationToken);
            }

            // STEP 2: Insert new row at index
            var rowId = Guid.NewGuid().ToString();
            var json = JsonSerializer.Serialize(row);

            using (var insertCmd = _connection.CreateCommand())
            {
                insertCmd.CommandText = @"
                    INSERT INTO DataRows (RowId, RowIndex, LastModified, CreationType, DataJson)
                    VALUES (@rowId, @rowIndex, @lastModified, @creationType, @dataJson)";

                insertCmd.Parameters.AddWithValue("@rowId", rowId);
                insertCmd.Parameters.AddWithValue("@rowIndex", index);
                insertCmd.Parameters.AddWithValue("@lastModified", DateTime.UtcNow.ToString("o"));
                insertCmd.Parameters.AddWithValue("@creationType",
                    row.TryGetValue("__creationType", out var ct) ? ct?.ToString() ?? "UserInserted" : "UserInserted");
                insertCmd.Parameters.AddWithValue("@dataJson", json);

                await insertCmd.ExecuteNonQueryAsync(cancellationToken);
            }

            transaction.Commit();

            // Clear cache (indices changed!)
            _hotCache.Clear();

            _logger.LogInformation("Inserted row at index {Index}", index);
        }
        finally
        {
            _dbLock.Release();
        }
    }

    /// <summary>
    /// Removes rows by IDs.
    /// </summary>
    public async Task RemoveRowsAsync(
        IReadOnlyList<string> rowIds,
        CancellationToken cancellationToken = default)
    {
        if (!rowIds.Any())
            return;

        await _dbLock.WaitAsync(cancellationToken);
        try
        {
            using var transaction = _connection.BeginTransaction();

            // Delete rows
            foreach (var rowId in rowIds)
            {
                using var command = _connection.CreateCommand();
                command.CommandText = "DELETE FROM DataRows WHERE RowId = @rowId";
                command.Parameters.AddWithValue("@rowId", rowId);
                await command.ExecuteNonQueryAsync(cancellationToken);
            }

            // Reindex (ensure continuous 0,1,2,...)
            await ReindexRowsAsync(cancellationToken);

            transaction.Commit();

            // Clear cache
            _hotCache.Clear();

            _logger.LogInformation("Removed {Count} rows and reindexed", rowIds.Count);
        }
        finally
        {
            _dbLock.Release();
        }
    }

    /// <summary>
    /// Replaces ALL rows (clear + bulk insert).
    /// </summary>
    public async Task ReplaceAllRowsAsync(
        IEnumerable<IReadOnlyDictionary<string, object?>> rows,
        CancellationToken cancellationToken = default)
    {
        await _dbLock.WaitAsync(cancellationToken);
        try
        {
            using var transaction = _connection.BeginTransaction();

            // Clear all
            ExecuteNonQuery("DELETE FROM DataRows");

            // Bulk insert
            int rowIndex = 0;
            foreach (var row in rows)
            {
                var rowId = Guid.NewGuid().ToString();
                var json = JsonSerializer.Serialize(row);

                using var command = _connection.CreateCommand();
                command.CommandText = @"
                    INSERT INTO DataRows (RowId, RowIndex, LastModified, CreationType, DataJson)
                    VALUES (@rowId, @rowIndex, @lastModified, @creationType, @dataJson)";

                command.Parameters.AddWithValue("@rowId", rowId);
                command.Parameters.AddWithValue("@rowIndex", rowIndex++);
                command.Parameters.AddWithValue("@lastModified", DateTime.UtcNow.ToString("o"));
                command.Parameters.AddWithValue("@creationType",
                    row.TryGetValue("__creationType", out var ct) ? ct?.ToString() ?? "Imported" : "Imported");
                command.Parameters.AddWithValue("@dataJson", json);

                await command.ExecuteNonQueryAsync(cancellationToken);
            }

            transaction.Commit();

            // Clear cache
            _hotCache.Clear();

            _logger.LogInformation("Replaced all rows with {Count} new rows", rowIndex);
        }
        finally
        {
            _dbLock.Release();
        }
    }

    /// <summary>
    /// Updates single row.
    /// </summary>
    public async Task UpdateRowAsync(
        int rowIndex,
        IReadOnlyDictionary<string, object?> rowData,
        CancellationToken cancellationToken = default)
    {
        await _dbLock.WaitAsync(cancellationToken);
        try
        {
            var json = JsonSerializer.Serialize(rowData);

            using var command = _connection.CreateCommand();
            command.CommandText = @"
                UPDATE DataRows
                SET DataJson = @dataJson, LastModified = @lastModified
                WHERE RowIndex = @rowIndex";

            command.Parameters.AddWithValue("@dataJson", json);
            command.Parameters.AddWithValue("@lastModified", DateTime.UtcNow.ToString("o"));
            command.Parameters.AddWithValue("@rowIndex", rowIndex);

            await command.ExecuteNonQueryAsync(cancellationToken);

            // Invalidate cache entry
            _hotCache.Remove(rowIndex);

            _logger.LogTrace("Updated row at index {Index}", rowIndex);
        }
        finally
        {
            _dbLock.Release();
        }
    }

    /// <summary>
    /// Gets total row count.
    /// </summary>
    public async Task<int> GetRowCountAsync(CancellationToken cancellationToken = default)
    {
        await _dbLock.WaitAsync(cancellationToken);
        try
        {
            return await GetRowCountInternalAsync();
        }
        finally
        {
            _dbLock.Release();
        }
    }

    // ========================================
    // HELPER METHODS

    private async Task<int> GetRowCountInternalAsync()
    {
        using var command = _connection.CreateCommand();
        command.CommandText = "SELECT COUNT(*) FROM DataRows";
        var result = await command.ExecuteScalarAsync();
        return Convert.ToInt32(result);
    }

    private async Task ReindexRowsAsync(CancellationToken cancellationToken)
    {
        // Ensures continuous indices: 0, 1, 2, ...
        ExecuteNonQuery(@"
            UPDATE DataRows
            SET RowIndex = (
                SELECT COUNT(*) - 1
                FROM DataRows AS D2
                WHERE D2.RowId <= DataRows.RowId
            )");

        _logger.LogDebug("Rows reindexed");
    }

    private void ExecuteNonQuery(string sql)
    {
        using var command = _connection.CreateCommand();
        command.CommandText = sql;
        command.ExecuteNonQuery();
    }

    public void Dispose()
    {
        if (_disposed)
            return;

        _disposed = true;

        _dbLock.Dispose();
        _connection.Close();
        _connection.Dispose();

        _logger.LogInformation("HybridRowStore disposed");
    }
```

#### LRUCache Implementation

**Súbor:** LRUCache.cs (NOVÝ)

```csharp
using System.Collections.Generic;
using System.Linq;

namespace RpaWinUiComponentsPackage.AdvancedWinUiDataGrid.Infrastructure.Persistence;

/// <summary>
/// Thread-safe LRU cache for hot data.
/// </summary>
internal sealed class LRUCache<TKey, TValue>
    where TKey : notnull
{
    private readonly int _capacity;
    private readonly Dictionary<TKey, LinkedListNode<CacheItem>> _cache;
    private readonly LinkedList<CacheItem> _lruList;
    private readonly object _lock = new();

    public LRUCache(int capacity)
    {
        _capacity = capacity;
        _cache = new Dictionary<TKey, LinkedListNode<CacheItem>>(capacity);
        _lruList = new LinkedList<CacheItem>();
    }

    public bool TryGet(TKey key, out TValue? value)
    {
        lock (_lock)
        {
            if (_cache.TryGetValue(key, out var node))
            {
                // Move to front (most recently used)
                _lruList.Remove(node);
                _lruList.AddFirst(node);

                value = node.Value.Value;
                return true;
            }

            value = default;
            return false;
        }
    }

    public void Add(TKey key, TValue value)
    {
        lock (_lock)
        {
            if (_cache.TryGetValue(key, out var existingNode))
            {
                // Update and move to front
                existingNode.Value.Value = value;
                _lruList.Remove(existingNode);
                _lruList.AddFirst(existingNode);
                return;
            }

            // Evict LRU if at capacity
            if (_cache.Count >= _capacity)
            {
                var lruNode = _lruList.Last;
                if (lruNode != null)
                {
                    _cache.Remove(lruNode.Value.Key);
                    _lruList.RemoveLast();
                }
            }

            // Add new item
            var newItem = new CacheItem(key, value);
            var newNode = _lruList.AddFirst(newItem);
            _cache[key] = newNode;
        }
    }

    public void Remove(TKey key)
    {
        lock (_lock)
        {
            if (_cache.TryGetValue(key, out var node))
            {
                _cache.Remove(key);
                _lruList.Remove(node);
            }
        }
    }

    public void Clear()
    {
        lock (_lock)
        {
            _cache.Clear();
            _lruList.Clear();
        }
    }

    private sealed class CacheItem
    {
        public TKey Key { get; }
        public TValue Value { get; set; }

        public CacheItem(TKey key, TValue value)
        {
            Key = key;
            Value = value;
        }
    }
}
```

   - ✅ Stále potrebný (viewport buffer)
   - ✅ Spolupracuje s SQLite (nie duplikácia!)
